## 5. Iteration bar (loose on purpose)

**Accept** a layer experiment when **all** hold:

| Check | Bar |
| --- | --- |
| n remaining after skips | Report; tip base ~94; no n≥385 floor |
| Tip-window E_N / EF | ≥ baseline − **1 pp** EF (or E_N hold if Leak pending) |
| MaxDD | ≤ baseline + **2 pp** (~3.4% tip proxy → soft ≤5.4%) |
| 90d fire count | ≥ 50% of tip baseline rate → else FREQUENCY_STALL **warn** |
| AL | Not worse unless E_N clearly improved |
| Bad-cell hit rate | Skips concentrated in M5 registry cells (report precision/recall vs winners) |
| Protect cells | False-skip rate on **Jul / Jun / Oct / OFFHOME** must be reported; high FP → REJECT |

**Reject immediately** when:

- WR↑ but E_N↓ or EF↓  
- Layer invents entries / changes SL/TP/ATR band / BB / session as “OS”  
- Thins SL below ~25000 or lifts MaxSpread as a Leak “fix”  
- Higher layer overrides L3 halt  
- Uses M15 `L2det_jp` / May∨Jul / EUR / UK / DE / AUD / AAPL pin on M5  
- Permanently disables a side/DOW before tape exists  
- Claims Robust / production on Leak **prior** alone  
- Rejects asset solely on Aug–Sep MATCH tax  
- Blanket-skips all FRAGILE / all MISMATCH (Jun/Jul/Oct pay)

**Promote (JP225-M5-AOS-P7 only)** when: tip May→Oct scored · shadow CF beats/holds baseline · L3/L4 wired · ledger complete · measured Leak preferred · HITL sign-off under `edge_framework.md`. Live capital stays off JP225 M5 until then. Expansion research OS ≠ live FX replace.
